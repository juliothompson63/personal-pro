# Roadmap

Este roteiro descreve possibilidades futuras. Itens concluídos estão marcados; os demais são propostas, não funcionalidades já entregues.

## Qualidade e manutenção

- [x] Adicionar verificação automatizada de build no GitHub Actions.
- [x] Remover o catálogo remoto de exercícios não utilizado nesta demonstração.
- [ ] Adicionar testes automatizados de componentes e fluxos principais.
- [ ] Revisar acessibilidade: navegação por teclado, rótulos, contraste e responsividade.
- [ ] Adicionar validação e estados de erro úteis aos formulários.
- [x] Fixar versões diretas de dependências.
- [x] Configurar Dependabot para atualizações semanais.
- [ ] Versionar um lockfile npm para instalações reproduzíveis.

## Produto

- [ ] Documentar os fluxos de profissional e aluno com capturas de tela.
- [ ] Melhorar criação de treinos e organização dos exercícios.
- [ ] Adicionar histórico de evolução mais claro para alunos.
- [ ] Adicionar opções de exportação e backup dos registros de treino.
- [ ] Planejar backend e autenticação com controles de privacidade antes de usar dados reais.

## Comunidade

- [ ] Triar issues recebidas.
- [ ] Revisar e responder pull requests.
- [ ] Publicar notas de versão para mudanças relevantes.

Sugestões e relatos de bugs são bem-vindos por meio do GitHub Issues.
