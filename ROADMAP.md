# Roadmap

This roadmap describes possible next steps. Items are proposals, not claims that the work is already complete.

## Near term

- [ ] Document the trainer and student workflows with screenshots.
- [ ] Add automated checks for the production build.
- [ ] Review accessibility: keyboard navigation, labels, contrast, and responsive layouts.
- [ ] Add validation and helpful error states to forms.
- [ ] Document the Supabase schema and Row Level Security policies.

## Product improvements

- [ ] Improve workout creation and exercise organization.
- [ ] Add clearer progress history for students.
- [ ] Add export and backup options for training records.
- [ ] Replace mocked AI/re-engagement flows only after defining privacy and cost controls.

## Community

- [ ] Triage incoming issues.
- [ ] Review and respond to pull requests.
- [ ] Publish release notes for meaningful changes.

Suggestions and bug reports are welcome through GitHub Issues.
