# Personal Pro — demonstração

Aplicação demonstrativa para apresentar fluxos de acompanhamento de alunos e organização de treinos para personal trainers.

**Esta versão é apenas uma demonstração.** Os nomes, e-mails, métricas, treinos e registros exibidos são fictícios. Não insira dados pessoais, dados de saúde, credenciais ou informações reais de alunos.

## Executar localmente

```bash
npm install
npm run dev
```

Abra o endereço local indicado pelo Vite.

## Como testar

- Explore o painel, a carteira fictícia, os treinos e a evolução.
- Use **Ver experiência do aluno** para alternar para a visão demonstrativa do aluno.
- As alterações ficam apenas no armazenamento local do navegador (`localStorage`).

## Privacidade e segurança

- Não há cadastro, login, autenticação ou sincronização com servidor nesta versão.
- Não há integração ativa com Supabase ou serviços externos de IA.
- Não use dados reais. O armazenamento local do navegador não é um ambiente seguro para informações confidenciais.
- Nunca publique chaves, tokens, senhas, arquivos de ambiente ou dados pessoais.

## Escopo

Este repositório contém somente o código-fonte necessário para a demonstração. Funcionalidades de backend, autenticação, pagamentos e IA real não fazem parte desta versão.
